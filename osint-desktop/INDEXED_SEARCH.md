# Indexed desktop integration

Run `python indexed.py` from osint-desktop with Python 3.12 and Tk. This launcher extends app.py, preserves the existing pair comparison and evidence export tools, adds persistent SQLite FTS5 search, pages results in groups of 100, and adds an opt-in resumable NYC PLUTO downloader. Search uses AND-combined token prefixes across stored fields, not fuzzy person resolution. Native publisher files still need schema mapping if imported manually.

Persistent records live in the Windows per-user LocalAppData/CandyLandOSINT directory. Data and JSON exports are NOT encrypted. Uninstalling the program does not remove that user database. No database migration from other development source packages is implemented. CSV imports preserve source IDs when supplied; generated IDs are hashes of complete rows and are not person identifiers. Court/voter source links remain manual/external. Candidate discovery currently compares the visible page only, not the entire database.

Only NYC PLUTO ingestion is implemented. No preloaded nationwide data, no hosted index, no live court or voter integration, no automatic identity merges and no guarantee of coverage. The property downloader requires internet and available disk space. Publisher system IDs are checkpointed; API scans are not consistent snapshots. Changes/deletions to already downloaded rows and publisher republishing are not reconciled. Full refresh, persistent ingest status history, state-specific reuse checks, protected-record handling, source freshness reconciliation and production-grade matching remain outstanding.

Official property source: https://data.cityofnewyork.us/City-Government/Primary-Land-Use-Tax-Lot-Output-PLUTO-/64uk-42ks . Source schema and live pagination must be tested before describing ingestion as verified. Ownership is not residence or confirmed current legal title. Do not use this prototype for consequential eligibility decisions.

The Windows workflow now packages indexed.py and runs both matching and index tests. It is manual-only and does not publish a release. Windows GUI, downloader and installer testing are still required. No installer is bundled in this commit. This integration is not identical to the standalone development ZIP: it intentionally reuses the original app rather than replacing its comparison screen. State/type dropdowns from the standalone ZIP are not included; those values remain searchable as text if present in records.
