🎬 VIDEO

Storyboards, not rendered videos

These chat models can plan shots, scripts and prompts; none of the listed GGUF language models produces finished videos in Random AI. Real video generation requires a separate video engine and device verification.

Open a downloaded model on any device

  1. Tap Download actual .gguf and let your browser save the complete file. Check Downloads or Files; your browser chooses the folder.
  2. Phones and tablets: try PocketPal AI on supported devices. In PocketPal choose Models → + → Local storage and select the GGUF file. Laptops and desktops: try LM Studio on supported Windows, macOS or Linux computers, or another GGUF-compatible app, and import the file.
  3. Tap Load in that app, then chat offline if the model fits your device's RAM and storage. To analyze photos with Qwen3-VL, use an app that supports both its language GGUF and mmproj vision projector.

Visitors select a task stack and chat without downloading models or providing API keys. The owner’s secure Cloudflare Worker handles limited free hosted inference.

Checking service…
  1. Deploy the existing studio-free-ai/ Cloudflare Worker from your account.
  2. Add its public HTTPS workers.dev URL to public/studio/free-config.js in GitHub. Never add secret credentials to public files.
  3. Publish the website, then choose Instant AI in Chat and check the connection.

Cloudflare has usage limits. Instant AI is not unlimited; your local mode remains the no-API-cost option.
