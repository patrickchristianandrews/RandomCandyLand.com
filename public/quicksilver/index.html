Install

  1. Download and unzip everything into one folder.
  2. Run Quicksilver-Setup. If the Quicksilver models folder came with it, keep it next to the installer so the full model installs straight away.
  3. If Windows says "Windows protected your PC", click More info, then Run anyway. (The installer isn't signed yet.)

Help us make it better

  1. Ask it something everyday, then something hard. Notice how long it takes and whether it's right.
  2. Drop in a photo or a PDF, and try the 🎤 mic.
  3. Click the 💬 speech bubble at the bottom of the sidebar to send feedback. Your chats and files are never included.

Updates arrive automatically once you've installed it: Quicksilver downloads new versions in the background and you choose when to restart.
