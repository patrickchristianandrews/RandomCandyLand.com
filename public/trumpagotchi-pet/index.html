🎮 How this version works · game rules & credits

This game renders the actual original pixel-art room, Trumpagotchi character, facial expressions, sleep poses, and moving animations ported directly from the GPL firmware's firmware/src/app/pet_art.h, alongside a standalone browser adaptation of the pet mechanics in Adam Charles Wilson's Trumpagotchi v1.0.0. Care actions are FEED, PRAISE, CLEAN, and REST; there is a five-minute day/night cycle, hunger and energy decay, automatic side snacks, occasional messes, moods, short care cooldowns, an optional musical interaction, pause and browser-local save. The original character and room use the original source drawing instructions, but the interface and care timers are browser adaptations, not a hardware-accurate emulator. Recorded voice playback, when enabled, uses whole pre-existing clips from Random Candy Land's own game, never stitched-together fake quotations.

The original game's code and original artwork are GPL-3.0-only. This HTML/JavaScript port is also offered under GPL-3.0-only, including the full browser port of the original drawing code, with the rest of its complete corresponding source available as the source of this page. Voice-recording rights are separate. The game is unofficial political parody; it is not affiliated with or endorsed by Donald Trump, the FM-1 manufacturer, or the source author.
