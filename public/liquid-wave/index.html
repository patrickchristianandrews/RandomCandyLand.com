About Liquid Wave

A free browser toy that writes a short song every time: drums, bass, chords, lead, pad, arpeggio and extras. Each character plays one channel. Sounds are simple FM synthesis made in your browser, with no samples and nothing uploaded.

Install Liquid Wave on your FM-1 (experimental)

Put the early Liquid Wave firmware on an M-VAVE FM-1 straight from this site. It has not been tested on a real FM-1, so go in carefully:

  1. Use Chrome or Edge on a computer, and a USB data cable. Close other apps that use the FM-1's MIDI.
  2. Back up your FM-1 first.
  3. Open the installer, try the Emulator tab, and read the Rescue tab.
  4. Press Install and allow MIDI access. Nothing is installed until you press it. Don't unplug while it writes.
Open the FM-1 installer & emulator Download emulator firmware (.fwsc)

Open the .fwsc file in an FM-1 emulator that supports firmware packages, or use the Emulator tab in the installer. The download contains the experimental hardware build. The animal sequencer above runs in this browser.

If the FM-1 ever won't start, hold OCT− while switching it on for the USB rescue. The package also has 26 companion DX7 bank files (browse them); the firmware itself cannot play them. The browser toy above does not need an FM-1.
