Important before installing: Firmware installation replaces the current firmware on a physical FM-1. You need an FM-1, a USB data cable and a computer with Python 3. Only the author's device/restart were verified for this exact release; do not force an update on unsupported hardware. You cannot flash the firmware from this web page.
Installation outline for hardware owners
  1. Download the official trumpagotchi.fwsc file and the matching trumpagotchi-source.zip.
  2. Extract the source archive and place the firmware file alongside its README and tools/ folder.
  3. Follow the source archive's installation guide to create a Python environment and install dependencies.
  4. Connect the FM-1 using a USB data cable; close other programs using the FM-1 MIDI port.
  5. Verify the device using python tools/fm1_install.py --info, then confirm the target before running python tools/fm1_install.py trumpagotchi.fwsc.
  6. Leave the cable connected until the update and restart finish; the expected device firmware identity is FM-1_710.
